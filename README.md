# Like Hero To Zero

Prototyp einer Webanwendung zu weltweiten CO₂-Emissionen, entstanden als Fallstudie im Kurs „Programmierung von industriellen Informationssystemen mit Java EE“ (IPWA02-01).

- **Öffentlicher Bereich:** aktuellster CO₂-Ausstoß eines Landes samt Verlauf, Daten der Weltbank (Data360 API)
- **Backend mit Login:** Wissenschaftler:innen erfassen neue Werte und korrigieren vorhandene

Technik: Jakarta Faces 4 (Mojarra) mit PrimeFaces, CDI (Weld), JPA mit Hibernate, MySQL 8, Apache Tomcat 10.1, Java 17, Maven.
